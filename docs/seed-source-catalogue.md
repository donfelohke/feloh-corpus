## Source handling rules

- Never cite a source merely because it appears in this catalogue.
- Record the exact passage, provision, page, commit, or test output supporting each claim.
- Preserve source version, retrieval date, and limitations.
- Label the researcher’s inference separately from the source’s own statement.
- Do not place client records, credentials, private messages, or sensitive personal data in the public corpus.
