## 10. Evidence vocabulary

Use these terms precisely:
- **DOCUMENTED:** written record exists.
- **RESEARCHED:** sources and reasoning have been examined.
- **PROPOSED:** design or method is specified but not implemented.
- **PROTOTYPED:** an experimental implementation exists.
- **IMPLEMENTED:** code or process exists in the stated environment.
- **TESTED:** a defined test was executed and results recorded.
- **VALIDATED:** evidence meets the stated acceptance criteria.
- **DEPLOYED:** the identified release is running or published in the target environment.
- **UNKNOWN:** evidence is insufficient.

A merged commit is not a deployment. A build is not runtime validation. A research note is not an implementation. An empty CI status response is not a passing test.
