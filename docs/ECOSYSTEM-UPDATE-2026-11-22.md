## Evidence and reuse requirements

Before proposing a new component or invention, search existing scholarship, standards, open-source software, hardware and prior art. Reuse, adapt, interoperate and credit creators. A fork is not an original invention. A merged document is not a prototype; a prototype is not a validated product; a passing source check is not deployment.

Use maturity labels consistently: LIVE / PRACTICE / RESEARCH / PROTOTYPE / CONCEPT / HISTORICAL / SUPERSEDED / UNKNOWN. Preserve contradictions, access dates, source locators, licences, rights and confidence. Unknown means unresolved, not implicitly approved.
