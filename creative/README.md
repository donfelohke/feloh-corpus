# FELOH Creative Archive

- Status: **CONCEPT / RESEARCH**
- Canonical home: FELOH Sovereign Corpus
- Publication: **UNREVIEWED — nothing in this directory is approved for public release by default**

This area is proposed for preserving original creative works and their editorial history. It is not a claim that all works have been located, imported, or verified.

## Principles

1. Preserve the original wording, source location, and known authorship.
2. Separate source work from edited edition, commentary, translation, transcription, and AI-assisted synthesis.
3. Record dates only when supported; otherwise use `UNKNOWN`.
4. Preserve revisions and meaningful contradictions rather than silently rewriting them.
5. Keep publication permission separate from repository presence.
6. Never treat creative text as sufficient evidence for a psychological diagnosis or sensitive personal inference.
7. Use relative links and plain, portable formats.
8. Link canonical decisions to the corpus decision-provenance protocol.

## Collections

- [Sun Burn — Black Musings](sun-burn-black-musings/README.md) — proposed collection home; original source inventory is still required.

## Suggested work record

Each work should have a stable identifier, title, attribution, source reference, date/status fields, publication state, revision history, and clearly separated editorial notes. Use the collection README and the research report to guide new records.

## Status vocabulary

Use the status labels in [the corpus glossary](../docs/glossary.md). For publication state, use one of:

- `PRIVATE` — not for public release.
- `UNREVIEWED` — publication permission or content review has not been established.
- `APPROVED` — explicitly approved for the stated audience/channel.
- `WITHDRAWN` — no longer approved for that channel; preserve the archival record where appropriate.

These publication labels do not replace the corpus maturity labels.
