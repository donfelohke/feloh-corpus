## Technology and evidence

WARENA and WARENA-governed IKAI infrastructure follow a native-first, libre-first, local-first, inspectable and reproducible policy. GNU is foundational, not an exclusionary boundary. JavaScript and web technologies are not approved WARENA/IKAI application runtimes; static documentation and publication are distinct.

Use explicit evidence labels: **VERIFIED · CORROBORATED · DISPUTED · UNVERIFIED · INTERPRETATION · OPINION · TESTIMONY · PROPOSAL**.

Use maturity labels: **LIVE · PROTOTYPE · RESEARCH · CONCEPT · HISTORICAL · SUPERSEDED · UNKNOWN**.

A file on `main` proves its presence on that branch only. A research note is not a prototype; a commit is not a deployment; a proposal is not an operational capability. Keep unknowns visible.

## GRACE · GRIT · GLORY — canonical identity relationship

The shared philosophy is expressed through three pillars and distinct practice domains:

- **GRACE → NAKEBUSEN:** beauty, heritage, craft, dignity and the only live commercial practice.
- **GRIT → WARENA:** libre-first technology, freedom, infrastructure, reproducibility and independent works.
- **GLORY → DON FELOH:** the human author, creative agency, expression and becoming.
- **GENJE:** embodied creative expression across Genge, sound, code, movement and choreography.
- **IKAI:** reflective computing and research, associated in a working, user-supplied name note with “home”; the proposed Turkana connection remains under linguistic verification.
- **FELOH CORPUS:** shared canon, governance, evidence and provenance.

**GENJE ZA WARENA | NAKEBUSEN** is the public-facing signature; it is not a corporate merger or new practice domain.
