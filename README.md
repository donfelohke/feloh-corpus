## Technology and evidence

WARENA and WARENA-governed IKAI infrastructure follow a native-first, libre-first, local-first, inspectable and reproducible policy. GNU is foundational, not an exclusionary boundary. JavaScript and web technologies are not approved WARENA/IKAI application runtimes; static documentation and publication are distinct.

Use explicit evidence labels: **VERIFIED · CORROBORATED · DISPUTED · UNVERIFIED · INTERPRETATION · OPINION · TESTIMONY · PROPOSAL**.

Use maturity labels: **LIVE · PROTOTYPE · RESEARCH · CONCEPT · HISTORICAL · SUPERSEDED · UNKNOWN**.

A file on `main` proves its presence on that branch only. A research note is not a prototype; a commit is not a deployment; a proposal is not an operational capability. Keep unknowns visible.
