## Evidence discipline

Evidence labels: VERIFIED · CORROBORATED · OWNER-APPROVED · UNVERIFIED · DISPUTED · INTERPRETATION · PROPOSAL · HISTORICAL.

Maturity labels: LIVE · PROTOTYPE · RESEARCH · CONCEPT · HISTORICAL · SUPERSEDED · UNKNOWN.

A commit is not a deployment. An upstream version is not a host. A public URL in a README is not proof of account ownership or monitoring. Mark UNKNOWN when evidence is missing.
