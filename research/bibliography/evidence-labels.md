# Controlled evidence labels (bibliography / claims)

**Canonical policy:** [EVIDENCE-AND-EDITORIAL-STANDARDS.md](../../EVIDENCE-AND-EDITORIAL-STANDARDS.md)

Use claim-level labels. A source may be authentic while a claim drawn from it remains disputed.

| Label | Meaning |
|-------|--------|
| **VERIFIED** | The specific statement has been checked against identified evidence. |
| **CORROBORATED** | Supported by multiple independent sources (check shared originals). |
| **ATTRIBUTED** | A source makes the claim; independent verification not established. |
| **INTERPRETATION** | Analytical reading or explanation of evidence. |
| **OPINION** | Clearly attributed personal or normative judgement. |
| **TESTIMONY** | First-person account; evidence of report/memory, not auto-proof of every external detail. |
| **HYPOTHESIS** | Proposition requiring further investigation. |
| **DISPUTED** / **CONTESTED** | Credible sources disagree or evidence remains disputed. |
| **UNVERIFIED** | Assertion has not yet undergone required checks. |
| **UNKNOWN** | Evidence missing, inaccessible, ambiguous or insufficient. |
| **PROPOSAL** | Recommended future action; not necessarily implemented. |

Do not upgrade OPINION, INTERPRETATION, TESTIMONY or UNVERIFIED to VERIFIED by repetition alone.
